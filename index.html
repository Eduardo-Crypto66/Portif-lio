O que ele resolve

Do escritório ao pé da lavoura.

  • Área real, não estimada. Desenhe o talhão no mapa ou importe KML; hectares calculados com PostGIS.
  • Custo por hectare. Insumos, máquinas e mão de obra apropriados a cada operação.
  • Rastreabilidade. Placa com QR Code: qualquer um consulta aplicações e carência pelo celular.
  • Roda sem banco. Modo demonstração em memória — liga o Supabase só com variáveis de ambiente.
  • Lançamento por WhatsApp. Nota fiscal e operação rápida via n8n + Meta Cloud API, sempre com confirmação.

Decisões de projeto

Planejado em 7 fases antes do primeiro commit.

  • Dinheiro em centavos. Inteiros no banco, sem erro de ponto flutuante.
  • Recorrência que não escorrega. “Todo dia 31” continua 31 quando o mês permite.
  • Nada é apagado. Arquivamento com archivedAt — histórico sempre íntegro.
  • API por token. Pronta para o mesmo n8n que já atende o AgroPlan.
03 — Trabalho · saúde / diagnóstico por imagem

Integrar por configuração

Na empresa onde trabalho, cada hospital novo exigia alterar o integrador em Delphi. Propus e prototipei um conector configurável: um formato canônico de exame + um arquivo de mapeamento por cliente. Cliente novo vira configuração, não código.

Exemplo ilustrativo do mapeamento (dados fictícios).

// clientes/hospital-exemplo/config.json { "origem": { "tipo": "api", "metodo": "GET", "paginacao": "page" }, "intervalo_min": 5, "mapeamento": { "accession_number": "$.exame.codigo", "paciente_nome": "$.paciente.nome", "modalidade": "$.exame.modalidade" } }

Pronto para implantar

Pensado para quem instala, não só para quem programa.

  • Sem dependências. Python só com biblioteca padrão, empacotado em um único .exe.
  • Instalador de um clique. Cria a tarefa agendada como serviço; desinstalador incluso.
  • Modos de teste. --offline e --simular para validar sem tocar produção.
  • Validado em API real. 24h de exames, paginação ok, zero erros.

WhatsApp → sistema

Automação com n8n e Meta Cloud API: o produtor fala, o sistema entende e só grava depois de confirmar.

Eu gosto de software que aguenta o mundo real — conexão ruim, regra de negócio estranha, usuário com pressa.

Trabalho com integração de sistemas na área de saúde e, em paralelo, construo meus próprios produtos. Começo pelo papel: documento, modelo os dados e registro cada decisão com o porquê. Depois construo em camadas, para que trocar o banco ou a tela não quebre a regra.

Me importo com segurança desde o início — isolamento por cliente, validação no servidor, nada de segredo no front — e com a experiência de quem vai usar no celular, no meio da lavoura ou do expediente.
